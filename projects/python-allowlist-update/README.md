# Python Allow List Update — Healthcare Access Control

This project demonstrates how to use Python to update an allow list of IP addresses for a healthcare company.
The allow list determines which employees can access a restricted subnetwork containing sensitive patient information.

The algorithm reads the allow list from a file, compares it to a remove list,
removes any matching IP addresses, and updates the file with the revised list.
