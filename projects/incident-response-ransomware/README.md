# Ransomware Incident Response — Healthcare Clinic

This project documents the investigation and response to a ransomware attack affecting a small U.S. healthcare clinic. The incident resulted in encrypted patient data, operational shutdown, and significant business disruption.

The project demonstrates practical incident‑response skills, including journal documentation, scenario analysis, and professional reporting.

---

## 📄 Included Documents

- **scenario.md** — description of the ransomware incident  
- **incident_journal_filtered.md** — filtered journal entries relevant to the incident
- **incident_journal_filtered.pdf** — filtered journal entries relevant to the incident 
- **Incident_handler's_journal.pdf** — full incident handler's journal

---

## 🎯 Objectives

- Analyze a real‑world ransomware scenario  
- Document incident details using the 5 W’s  
- Produce a professional incident report  
- Identify root causes and indicators of compromise  
- Recommend remediation and prevention strategies  

---

## 🧩 Skills Demonstrated

- Incident response documentation  
- Ransomware analysis  
- Root cause identification  
- Security control evaluation  
- Professional reporting  
- Communication of technical risks to stakeholders  

---

## 🛡️ Summary

The attack was caused by a targeted phishing campaign that deployed ransomware across the clinic’s network. Lack of training, insufficient security controls, and absence of backups significantly increased the impact.

The report provides actionable recommendations to strengthen the clinic’s security posture and prevent similar incidents in the future.
