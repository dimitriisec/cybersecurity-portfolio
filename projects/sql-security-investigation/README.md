# SQL Security Investigation — Filtering Login Attempts

This project focuses on investigating suspicious login activity using SQL queries. As a security professional, you analyze data from the `employees` and `log_in_attempts` tables to identify potential security issues, unauthorized access attempts, and anomalies in authentication behavior.

The project demonstrates how SQL filtering can be used as a cybersecurity investigation tool.

## 🎯 Objectives

- Retrieve specific records using SQL filters  
- Investigate suspicious login attempts  
- Correlate employee data with authentication logs  
- Identify unauthorized or abnormal access patterns  
- Strengthen security posture through data‑driven analysis
