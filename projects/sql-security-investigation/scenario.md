# Scenario

This project simulates a security investigation involving suspicious login activity inside a large organization. As a security professional, your responsibility is to analyze authentication data and identify potential security issues.

You recently discovered anomalies involving login attempts and employee machines. To investigate these issues, you must examine the organization’s data stored in two tables:

- **employees**
- **log_in_attempts**

Your task is to:

- Use SQL filters to retrieve specific records  
- Analyze login patterns  
- Identify suspicious activity  
- Determine whether unauthorized access attempts occurred  
- Document findings and recommend next steps  

This project demonstrates practical SQL skills used in cybersecurity investigations, including filtering, pattern matching, and correlating data across multiple tables.
