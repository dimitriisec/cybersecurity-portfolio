# This scenario is fictional:

This project simulates a file permissions audit in a large organization. As a security professional working closely with the research team, your responsibility is to ensure that users have the correct authorization levels for files and directories. Proper permissions help maintain system security and prevent unauthorized access.

Your task is to:

- Examine existing permissions on the file system  
- Determine whether the permissions match the required authorization  
- Modify permissions where necessary  
- Remove unauthorized access and enforce correct access levels  

This project demonstrates practical Linux security administration skills, including auditing permissions, interpreting permission strings, and applying changes using the `chmod` command.
