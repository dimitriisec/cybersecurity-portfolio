# Scenario

You are a security analyst for a travel agency that advertises sales and promotions on the company’s website. Employees regularly access the company’s sales webpage to search for vacation packages for customers.

One afternoon, your monitoring system sends an automated alert indicating a problem with the web server. When you attempt to visit the company’s website, your browser displays a connection timeout error.

You capture network traffic using a packet sniffer and observe a large number of TCP SYN requests coming from an unfamiliar IP address. The web server is overwhelmed by the volume of incoming SYN packets and is unable to respond to legitimate requests. You suspect the server is under attack by a malicious actor.

You temporarily take the server offline to allow it to recover and configure the firewall to block the suspicious IP address. However, you know this is only a temporary solution because attackers can spoof IP addresses to bypass simple blocking.

You must notify your manager about the issue, explain the type of attack, describe how it affected the server and employees, and recommend next steps to prevent similar incidents in the future.
