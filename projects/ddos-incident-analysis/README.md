# DDoS Incident Analysis and NIST CSF Application

This project analyzes a fictional distributed denial-of-service (DDoS) attack that disrupted a multimedia company’s internal network. The goal of this project is to examine the incident, identify root causes, and apply the NIST Cybersecurity Framework (CSF) to develop a comprehensive security improvement plan.

The project demonstrates foundational cybersecurity skills, including incident analysis, network security evaluation, and application of industry frameworks.

## 🛡️ Summary of Findings

The attack succeeded due to an **unconfigured firewall**, which allowed a flood of ICMP packets to overwhelm the network.  
The company lacked:

- ICMP rate limiting  
- Source IP verification  
- IDS/IPS filtering  
- Continuous network monitoring  

After the incident, the organization implemented new firewall rules, monitoring tools, and detection systems to prevent similar attacks.
